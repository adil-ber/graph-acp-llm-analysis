### Few-shot Example 1 (An element-level rule contains a condition on a specific attribute and rule exists for that same specific attribut)

INPUT:

('nodes', 'Invoice', 'Accountant')
R1: grant create on nodes (e:Invoice) where e.total < 10000 to Accountant;
R2: grant add{total} on nodes (e:Invoice) to Accountant;
R3: grant remove{date} on nodes (e:Invoice) to Accountant;

OUTPUT:

{
  "to remove": {
    "R2": "R1 can be bypassed using R2",
    "R3": "R1 can be bypassed using R3",
  }
}

### Few-shot Example 2 (An element-level rule contains a condition on a specific attribute and rule exists for wildcard (*))

INPUT:

('nodes', 'Invoice', 'Accountant')
R3: deny create on nodes (e:Invoice) where e.total < 10000 to Accountant;
R4: grant modify{*} on nodes (e:Invoice) to Accountant;

OUTPUT:

{
  "to add": {
    "R11": "deny modify{total} on nodes (e:Invoice) to Accountant;
  }
}
